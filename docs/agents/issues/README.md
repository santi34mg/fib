# Analysis issues

Analysis work is tracked on [GitHub](https://github.com/santi34mg/fib/issues).
Keep report bodies, progress, and discussion there—not as copies in this repository.

- [#9 — Name/type resolution and member lookup](https://github.com/santi34mg/fib/issues/9)
- [#10 — Binding inference, const enforcement, and initialization](https://github.com/santi34mg/fib/issues/10)
- [#11 — Operators, assignments, casts, and pointers](https://github.com/santi34mg/fib/issues/11)
- [#12 — Functions, calls, returns, and generics](https://github.com/santi34mg/fib/issues/12)
- [#13 — Aggregates, arrays, slices, and bounds](https://github.com/santi34mg/fib/issues/13)
- [#14 — Control flow, enum patterns, and defer](https://github.com/santi34mg/fib/issues/14)

These implementation tasks reference the [type-system design RFC #2](https://github.com/santi34mg/fib/issues/2).
They do not establish language-design decisions from current parser behavior.
Verified syntax remains in [the parsing reference](../../parsing/README.md).
